# B8A1 — Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment demonstrates practical use of core TypeScript concepts from Modules 1–3. The coding portion is contained in [`solutions.ts`](./solutions.ts) and covers:

- Basic types, optional parameters, and default values
- Union types with type narrowing (`typeof`)
- `readonly` tuples
- Generic functions with rest parameters and `keyof` constraints
- Interfaces and non-mutating array operations
- Classes, inheritance, and `public` / `private` / `protected` access modifiers
- Asynchronous programming with `Promise<T>`, `setTimeout`, and error rejection

All functions and class methods declare explicit parameter and return types, and the solutions avoid `any`.
